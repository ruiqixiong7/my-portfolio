# ROMANCE SIGNAL

一款以电脑桌面为舞台的中文互动叙事游戏。一个自称了解你过去的陌生人突然出现在屏幕里，邀请你进行一场午夜约会。随着聊天推进，你需要决定相信什么、打开哪些记忆，以及何时结束连接。

## 游戏内容

- 通过点击推进对话，在关键时刻选择回应。
- 在模拟的桌面窗口中探索歌曲、照片与旧聊天记录。
- 根据选择进入不同剧情分支，解锁三个结局：**下次约会、访问记录、断开连接**。
- 使用浏览器本地存储保存章节进度及已解锁结局。

## 如何游玩

1. 下载本仓库：点击页面上的 **Code → Download ZIP**，解压文件夹。
2. 用 VS Code 打开解压后的文件夹，并通过 **Live Server** 打开 `index.html`；也可以用其他本地静态服务器运行。
3. 点击标题画面进入菜单，选择「开始游戏」。点击画面推进对话，在出现选项时选择你的回答。

游戏菜单提供「继续游戏」「结局收集」「玩法说明」；页面右上角可以切换全屏。建议使用电脑浏览器游玩。

## 技术与文件

项目使用 **JavaScript、p5.js、HTML 和 CSS** 制作，无需构建步骤。p5.js 及 p5.sound 已包含在仓库中。

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面入口与全屏按钮 |
| `sketch.js` | 标题、菜单、开场及主画面交互 |
| `chapter.js` | 章节对话、选择、结局与存档 |
| `style.css` | 页面样式 |
| 图片、字体和 `mov1.mp4` | 游戏视觉与开场素材 |
